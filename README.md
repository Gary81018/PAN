# PAN

基于 [YUN](https://github.com/Gary81018/YUN) 制作的照片星河立方体，使用 12 张 PAN 照片。

## 效果

- 星空粒子背景、双层立方体自动旋转。
- 鼠标悬停时外层展开，显示内层照片。
- 每次打开随机排列 12 张照片，内外各 6 张，不重复、不遗漏。
- 保留 YUN 的桌面与移动端自适应布局。
- 右下角点击“播放音乐 · 李白”开启背景音乐，支持暂停、继续和单曲循环。页面不显示视频小窗。

## 音乐

背景音乐为单依纯《李白》，从用户提供的 MP4 中提取音轨，保存在 `web-assets/li-bai.m4a`。音频随网站一起部署，原始视频保留在项目外。

播放器使用原生 HTML audio，点击后才加载，音量为 60%，支持暂停与循环；不连接第三方播放器。首次访问仍需从网站加载音频，后续缓存由浏览器管理。

## 本地预览

在项目目录启动 HTTP 服务预览：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 照片与部署

照片位于 `web-assets/pan-01.jpg` 至 `pan-12.jpg`，由原始 HEIC 转换为兼容浏览器的 JPEG。

GitHub Pages 使用 `.github/workflows/pages.yml`，推送到 `main` 后自动部署。
