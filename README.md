# PAN

基于 [YUN](https://github.com/Gary81018/YUN) 制作的照片星河立方体，使用 12 张 PAN 照片。

## 效果

- 星空粒子背景、双层立方体自动旋转。
- 鼠标悬停时外层展开，显示内层照片。
- 每次打开随机排列 12 张照片，内外各 6 张，不重复、不遗漏。
- 保留 YUN 的桌面与移动端自适应布局。
- 右下角点击“播放音乐 · 李白”开启单依纯《李白》的背景音乐；点击“关闭音乐”停止。页面不显示视频小窗。

## 音乐

背景音乐通过[单依纯本人发布的《李白》](https://www.bilibili.com/video/BV1DyTgzmEmz/)（《歌手2025》舞台）的哔哩哔哩官方外链播放器播放，适合国内访问。播放器画面不展示，点击按钮后才加载，关闭时销毁播放器并停止播放；未下载或另行托管音频文件。播放可用性和自动播放限制由平台与浏览器控制。

## 本地预览

为确保第三方音乐播放器获取正确的来源信息，请在项目目录启动 HTTP 服务预览：

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 照片与部署

照片位于 `web-assets/pan-01.jpg` 至 `pan-12.jpg`，由原始 HEIC 转换为兼容浏览器的 JPEG。

GitHub Pages 使用 `.github/workflows/pages.yml`，推送到 `main` 后自动部署。
